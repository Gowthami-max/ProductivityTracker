Productivity Tracker
Version: 1.0 Description: Productivity Tracker is a Chrome extension that monitors your browsing activity, tracks the websites you visit, and helps analyze your online habits to improve efficiency.

Features
Website Tracking: Logs URLs of websites visited and time spent on each site.
Classification: Categorize websites as "Productive" or "Unproductive" for tailored analysis.
Data Storage: Saves browsing activity using Chrome's storage.local API.
Analytics Dashboard: Visualize productivity trends with charts and detailed reports.
Custom Alerts: Optional notifications for managing time on unproductive websites.

Installation
Open Chrome and go to chrome://extensions.
Enable Developer Mode (top-right corner).
Click Load Unpacked and select the ProductivityTracker folder.
The extension will appear in your browser bar.

How to Use
Activate Tracking:
Toggle the extension "on" from chrome://extensions.
Visit websites to start tracking activity.

View Analytics:
Click the extension icon to open the popup and view activity or access the dashboard.
Customize Settings:
Mark websites as "Productive" or "Unproductive" to refine your analysis.

Tech Stack
Frontend: HTML, CSS, JavaScript, React.js (optional for dashboard).
Backend: Node.js with Express.js (optional for extended functionality).
Database: MongoDB or Chrome’s storage.local.
